# Portfolio — Kenneth Tagne Nathan

Site portfolio personnel en React et Vite : présentation, compétences, expériences, projets, certifications, jeux, contact et CV.

## Démarrage rapide

Il faut Node.js 20 (version utilisée par le pipeline).

```bash
npm ci
cp .env.example .env
npm run dev
```

Renseignez `VITE_WEB3FORMS_KEY` dans `.env` pour activer le formulaire de contact.

## Scripts

| Commande | Action |
|---|---|
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production dans `dist/` |
| `npm run preview` | Aperçu local du build |
